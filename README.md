# StoryForge

Voice-first interactive storytelling for kids. Children talk to AI story characters using their real voice — the characters respond in real-time with ElevenLabs Conversational AI, and scenes are illustrated on-the-fly with Gemini image generation.

Built for the **ElevenHacks** hackathon.

---

## Features

- **Live voice conversations** with 10 built-in story characters (no typing)
- **Unique character voices** created with ElevenLabs Voice Design
- **Multilingual** — characters narrate in English, Hindi, Tamil, Mandarin, Spanish, and French
- **Dynamic scene illustrations** generated by Gemini as the story unfolds
- **Barge-in support** — children can interrupt and redirect the story naturally
- **Achievement badges** — awarded when children contribute creative ideas
- **Story recap** — illustrated storybook summary at the end of every session
- **Child-safe content moderation** on themes and all AI-generated content

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite + TypeScript + TailwindCSS + Framer Motion |
| Voice | `@elevenlabs/react` — `useConversation` hook |
| AI Characters | ElevenLabs Conversational AI (WebSocket, signed URL) |
| Voice Design | ElevenLabs Voice Design API |
| Images | Gemini (`gemini-3.1-flash-image-preview`) |
| Content Moderation | Gemini Flash Lite |
| Backend | Python FastAPI |
| Deployment | Replit |

## Quick Start

### 1. Clone and install

```bash
# Frontend
cd frontend && npm install

# Backend
cd backend && uv sync
```

### 2. Set up environment variables

Create `backend/.env`:

```env
ELEVENLABS_API_KEY=...
GEMINI_API_KEY=...
IMAGE_MODEL=gemini-3.1-flash-image-preview
```

### 3. Create characters and voices (one-time setup)

```bash
cd backend && uv run python setup_voices.py
```

Creates ElevenLabs Voice Design voices and Conversational AI agents for all characters. Writes `backend/character_ids.json` (gitignored — keep it safe).

To iterate on a single character without touching others:

```bash
uv run python setup_voices.py --char fairy
uv run python setup_voices.py --char fairy --force  # re-create even if exists
```

### 4. Run

```bash
bash start.sh
```

Builds the frontend and starts FastAPI at `http://localhost:8080`.

## Environment Variables

### Backend (`backend/.env`)

| Variable | Required | Description |
|---|---|---|
| `ELEVENLABS_API_KEY` | Yes | ElevenLabs API key |
| `GEMINI_API_KEY` | Yes | Google Gemini API key (AI Studio) |
| `IMAGE_MODEL` | No | Gemini image model (default: `gemini-3.1-flash-image-preview`) |

> On Replit, use **Replit Secrets** instead of `.env`. The frontend has no secret keys — all API keys stay server-side via the signed URL pattern.

```
│   ├── characters.py       # Character config, system prompts, voice styles
│   ├── image_gen.py        # Gemini image generation + content moderation

└── start.sh                # Build frontend + start backend
```

## API Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/session` | Get signed ElevenLabs WebSocket URL for a character |
| `POST` | `/api/image` | Generate a scene illustration via Gemini |
| `POST` | `/api/check-theme` | Moderate a story theme for child safety |
| `POST` | `/api/story-recap` | Generate story title + per-scene narrations |
