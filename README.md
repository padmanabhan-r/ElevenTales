# ElevenTales

Voice-first interactive storytelling for kids. Children talk to AI story characters using their real voice — the characters respond in real-time with ElevenLabs Conversational AI, and scenes are illustrated on-the-fly with Gemini image generation.

Built for the **ElevenHacks** hackathon.

---

## Features

- **Live voice conversations** with 5 built-in story characters (no typing required)
- **Unique character voices** created with ElevenLabs Voice Design API
- **Multilingual** — characters narrate in English, Hindi, and Tamil
- **Dynamic scene illustrations** generated by Gemini as the story unfolds
- **Dual illustration trigger** — agent calls `generate_illustration` tool every 4–6 sentences; frontend fallback fires if the agent doesn't
- **Magic Camera** — point at a toy or object; Gemini identifies it and builds the story around it, with a storybook illustration seeded as the visual anchor
- **Sketch Mode** — draw something; Gemini turns the sketch into a storybook illustration and weaves it into the story
- **Barge-in support** — children can interrupt and redirect the story naturally
- **Achievement badges** — awarded silently when children contribute creative ideas (max 3 per session)
- **Story recap** — illustrated storybook summary at the end of every session
- **Past Adventures** — gallery of all previous story sessions with their illustrations
- **Child-safe content moderation** on themes and all AI-generated content
- **Short-burst narration** — agent speaks 2–3 sentences then pauses for the child, never monologues
- **Voice Design** — create your own custom storyteller character with a unique AI-designed voice
- **Custom character management** — designed characters saved server-side and available across sessions
- **Tabbed character select** — Built-in Storytellers and My Created Storytellers in separate tabs

## Quick Start

### 1. Clone and install

```bash
# Frontend
cd frontend && npm install

# Backend
cd backend && uv sync
```

### 2. Set up environment variables

Create `backend/.env`:

```env
ELEVENLABS_API_KEY=...
GEMINI_API_KEY=...
IMAGE_MODEL=gemini-2.0-flash-preview-image-generation
```

### 3. Create characters and voices (one-time setup)

```bash
cd backend && uv run python setup_voices.py
```

Creates ElevenLabs Voice Design voices and Conversational AI agents for all 5 built-in characters. Writes `backend/character_ids.json` (gitignored — keep it safe).

To iterate on a single character without touching others:

```bash
uv run python setup_voices.py --char fairy
uv run python setup_voices.py --char fairy --force  # re-create even if exists
```

### 4. Run

```bash
bash start.sh
```

Builds the frontend and starts FastAPI at `http://localhost:8080`.

| `ELEVENLABS_API_KEY_BACKUP` | No | Backup key — silently swaps in on 429/quota errors |

## Voice Design (Custom Characters)

Children (or parents) can create their own storyteller with a unique AI-designed voice:

1. Navigate to **My Created Storytellers** tab → **Design a Voice**
2. Describe the character (name, personality, voice style, language)
3. Pick an emoji avatar
4. Listen to 3 generated voice previews and pick a favourite
5. The character is saved and immediately available to start a story

Under the hood:
- `POST /api/characters/design-previews` → ElevenLabs Voice Design API generates previews
- `POST /api/characters/save` → saves the selected voice, creates an ElevenLabs agent, writes to `custom_characters.json`
- Custom characters are returned by `GET /api/characters/custom` on every app load

## How Illustration Works

Illustrations are triggered two ways:

1. **Agent tool call** (`generate_illustration`) — the ElevenLabs agent calls this at story start, scene changes, character introductions, and dramatic moments. Roughly every 4–6 sentences.
2. **Frontend fallback** (`triggerImageGeneration`) — fires at most once per configured interval if the agent hasn't called the tool. Requires at least 150 characters of accumulated narration before the first trigger.

A **force cooldown** (8 seconds) prevents rapid-fire generation when the agent calls the tool in quick succession or when both the tool call and the fallback fire close together.

For Magic Camera and Sketch sessions, the prop/sketch illustration is seeded as `previous_image_data` for all subsequent Gemini image calls, giving visual continuity across the whole story.

## Agent Configuration

Each character agent is created by `setup_voices.py` with:

- **LLM**: `gemini-2.5-flash` (fast, reliable tool calling)
- **TTS**: `eleven_flash_v2` (English) or `eleven_multilingual_v2` (other languages)
- **TTS settings**: stability `0.5`, speed `1.0`, similarity boost `0.8`, streaming latency `3`
- **Turn timeout**: `7.0s`
- **Temperature**: `0.0`
- **Auth**: signed URL (no public access)
- **Dynamic variable**: `{{theme}}` — injected at session start with the child's chosen theme, prop label, or sketch description

To update agent config, edit `setup_voices.py` or `characters.py`, then re-create the agent:

```bash
cd backend && uv run python setup_voices.py --char fairy --force
```
