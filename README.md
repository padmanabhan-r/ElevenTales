# StoryForge

Voice-first interactive storytelling for kids. Children talk to AI story characters using their real voice — the characters respond in real-time with ElevenLabs Conversational AI, and scenes are illustrated on-the-fly with Gemini image generation.

Built for the **ElevenHacks** hackathon.

---

## Features

- **Live voice conversations** with story characters (no typing)
- **Unique character voices** created with ElevenLabs Voice Design
- **Family voice cloning** — clone Mum, Dad, or Grandma's voice as a character
- **Dynamic scene illustrations** generated by Gemini as the story unfolds
- **Barge-in support** — children can interrupt and redirect the story naturally
- **Child-safe content moderation** on all AI-generated content

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite + TypeScript + TailwindCSS + Framer Motion |
| Voice | `@elevenlabs/react` — `useConversation` hook |
| AI Characters | ElevenLabs Conversational AI (WebSocket, signed URL) |
| Voice Design | ElevenLabs Voice Design API (`eleven_ttv_v3`) |
| Voice Cloning | ElevenLabs Instant Voice Cloning (IVC) |
| Images | Gemini Flash (`gemini-2.0-flash-exp-image-generation`) |
| Backend | Python FastAPI |
| Deployment | Replit |

## Quick Start

### 1. Clone and install

```bash
# Frontend
cd frontend && npm install

# Backend
cd backend && uv sync
```

### 2. Set up environment variables

```bash
# Backend
cp backend/.env.example backend/.env
# Fill in ELEVENLABS_API_KEY and GEMINI_API_KEY

# Frontend (development only)
cp frontend/.env.example frontend/.env.local
```

### 3. Create characters and voices (one-time setup)

```bash
cd backend && python setup_voices.py
```

This script uses the ElevenLabs Voice Design API to generate unique voices for each built-in character and creates the Conversational AI agents.

### 4. Run

```bash
bash start.sh
```

Frontend: `http://localhost:5173`  
Backend API: `http://localhost:8080`

## Environment Variables

### Backend (`backend/.env`)

| Variable | Required | Description |
|---|---|---|
| `ELEVENLABS_API_KEY` | Yes | Primary ElevenLabs API key |
| `ELEVENLABS_API_KEY_BACKUP` | No | Fallback key used if primary hits quota |
| `GEMINI_API_KEY` | Yes | Google Gemini API key |
| `IMAGE_MODEL` | No | Gemini model for images (default: `gemini-2.0-flash-exp-image-generation`) |

### Frontend (`frontend/.env.local`)

| Variable | Required | Description |
|---|---|---|
| `VITE_API_URL` | Dev only | Backend URL (default: `http://localhost:8080`) |

> On Replit, use **Replit Secrets** instead of `.env` files. The frontend has no secret keys — the signed URL pattern keeps all API keys server-side.

## API Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/session` | Get signed ElevenLabs WebSocket URL for a character |
| `POST` | `/api/image` | Generate a scene illustration |
| `POST` | `/api/voice-clone` | Clone a family member's voice + create character |
