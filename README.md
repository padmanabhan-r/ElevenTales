# StoryForge

Voice-first interactive storytelling for kids. Children talk to AI story characters using their real voice — the characters respond in real-time with ElevenLabs Conversational AI, and scenes are illustrated on-the-fly with Gemini image generation.

Built for the **ElevenHacks** hackathon.

---

## Features

- **Live voice conversations** with 10 built-in story characters (no typing)
- **Unique character voices** created with ElevenLabs Voice Design API
- **Multilingual** — characters narrate in English, Hindi, Tamil, Mandarin, Spanish, and French
- **Dynamic scene illustrations** generated by Gemini as the story unfolds
- **Dual illustration trigger** — agent calls `generate_illustration` tool every 4–6 sentences; frontend fallback fires every 8 seconds if the agent doesn't
- **Magic Camera** — point at a toy or object; Gemini identifies it and builds the story around it, with a storybook illustration of the prop seeded as the visual anchor for all subsequent images
- **Sketch Mode** — draw something; Gemini turns the sketch into a storybook illustration and weaves it into the story
- **Barge-in support** — children can interrupt and redirect the story naturally
- **Achievement badges** — awarded silently when children contribute creative ideas (max 3 per session)
- **Story recap** — illustrated storybook summary at the end of every session
- **Past Adventures** — gallery of all previous story sessions with their illustrations
- **Child-safe content moderation** on themes and all AI-generated content
- **Short-burst narration** — agent speaks 2–3 sentences then pauses for the child, never monologues

## Quick Start

### 1. Clone and install

```bash
# Frontend
cd frontend && npm install

# Backend
cd backend && uv sync
```

### 2. Set up environment variables

Create `backend/.env`:

```env
ELEVENLABS_API_KEY=...
GEMINI_API_KEY=...
IMAGE_MODEL=gemini-2.0-flash-preview-image-generation
```

### 3. Create characters and voices (one-time setup)

```bash
cd backend && uv run python setup_voices.py
```

Creates ElevenLabs Voice Design voices and Conversational AI agents for all 10 characters. Writes `backend/character_ids.json` (gitignored — keep it safe).

To iterate on a single character without touching others:

```bash
uv run python setup_voices.py --char fairy
uv run python setup_voices.py --char fairy --force  # re-create even if exists
```

### 4. Run

```bash
bash start.sh
```

Builds the frontend and starts FastAPI at `http://localhost:8080`.

### Backend (`backend/.env`)

| Variable | Required | Description |
|---|---|---|
| `ELEVENLABS_API_KEY` | Yes | ElevenLabs API key |
| `ELEVENLABS_API_KEY_BACKUP` | No | Backup key — silently swaps in on 429/quota errors |
| `GEMINI_API_KEY` | Yes | Google Gemini API key (AI Studio) |
| `IMAGE_MODEL` | No | Gemini image model (default: `gemini-2.0-flash-preview-image-generation`) |

> On Replit, use **Replit Secrets** instead of `.env`. The frontend has no secret keys — all API keys stay server-side via the signed URL pattern.

## How Illustration Works

Illustrations are triggered two ways:

1. **Agent tool call** (`generate_illustration`) — the ElevenLabs agent calls this at the first story sentence, scene changes, character introductions, and dramatic moments. Roughly every 4–6 sentences.
2. **Frontend fallback** (`triggerImageGeneration`) — fires at most once every 8 seconds if the agent hasn't called the tool. Requires at least 150 characters of accumulated narration text before the first trigger.

For Magic Camera and Sketch sessions, the prop/sketch illustration is seeded as `previous_image_data` for all subsequent Gemini image calls, giving visual continuity across the whole story.

## Agent Configuration

Each character agent is created by `setup_voices.py` with:

- **LLM**: `gemini-2.5-flash` (fast, reliable tool calling)
- **TTS**: `eleven_flash_v2` (English) or `eleven_multilingual_v2` (other languages)
- **TTS settings**: stability `0.5`, speed `1.0`, similarity boost `0.8`, streaming latency `3`
- **Turn timeout**: `7.0s`
- **Temperature**: `0.0`
- **Auth**: signed URL (no public access)
- **Dynamic variable**: `{{theme}}` — injected at session start with the child's chosen theme, prop label, or sketch description

To update agent config, edit `setup_voices.py` or `characters.py`, then re-create the agent:

```bash
cd backend && uv run python setup_voices.py --char fairy --force
```
